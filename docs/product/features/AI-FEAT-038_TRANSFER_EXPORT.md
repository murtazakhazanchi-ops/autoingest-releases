## Summary

Writes a clean mirror of selected events from the Active Archive Root to a Transfer Drive, for physical transport to the Main Archive Root.

## Current Behavior

`services/transferExportService.js`. No-overwrite contract (AutoIngest runtime artefacts — `.autoingest/`, locks, sync queue, tmp — are excluded from the mirror). Atomic per-batch checkpoint. Writes `.autoingest-transfer/exports.audit.jsonl` for traceability. Country is never part of folder names generated by export.

**Concurrency note** (per `autoingest-architect` review): `docs/archive-operations-layer.md` describes a "single-export-at-a-time lock," but a direct grep of `services/transferExportService.js` for lock/guard patterns did not confirm this shares any mechanism with AI-FEAT-045's `archiveLockService.js` (which is SHA1-keyed with TTL+heartbeat, scoped to event/photographer editing). Treat Transfer Export's concurrency guard as a **distinct, unconfirmed mechanism** — do not assume it's the same lock system as AI-FEAT-045 until independently verified.
