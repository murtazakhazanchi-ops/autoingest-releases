# Memory Capsule Template

Copy this structure for every `docs/product/memory/AI-MEM-####_NAME.md` file. Delete this comment block when instantiating. Keep every section — write "Evidence pending — source conversation unavailable" rather than deleting a section that has nothing to report, per [16_ENGINEERING_MEMORY_POLICY.md](16_ENGINEERING_MEMORY_POLICY.md) § Reality Boundary.

A Memory Capsule is historical evidence, not a technical contract — see that policy document's § Authority before citing one as a reason to change current behavior.
